## About Me

I build robotics software for autonomous vehicles, spanning simulation,
control, and perception — with a focus on making it work in ROS 2, not just
on paper.

My work spans:

* **ROS 2 application development** (nodes, launch, packages)
* **Autonomous racing software stacks** (F1TENTH / RoboRacer)
* **Simulation-first development** for fast iteration before hardware
* **ML-based perception** (YOLO detection & segmentation) for real-world robots
* **Sensor data pipelines** (Intel RealSense, ROS bag processing)
* **Edge deployment** (TensorRT/ONNX export for onboard inference)

I like systems that are not just clever in simulation, but reliable on hardware.

## Featured Work

### Autonomous Racing Stack — [GR-roboracer](https://github.com/G-S-Rodrigues/GR-roboracer)

An autonomous racing software stack for the F1TENTH/RoboRacer platform, built on ROS 2 Jazzy.

* Simulation-first architecture with a dedicated sim adapter
* Baseline controllers (pure pursuit) with room to grow into more advanced planners
* Safety supervisor and metrics/recording packages for closed-loop evaluation
* Design decisions tracked as ADRs for traceability

### Vineyard Robot Perception — [Train_Yolo11_custom_dataset](https://github.com/G-S-Rodrigues/Train_Yolo11_custom_dataset)

Data + training pipeline for a custom YOLO detection/segmentation perception
stack, built for an autonomous vineyard robot (master's dissertation project).

* RealSense `.bag` recordings → labeled dataset (with SAM2-assisted auto-annotation)
* YOLOv8/v9 detection and YOLOv8-seg segmentation (trunk, post, person classes)
* Benchmarking and TensorRT export for real-time onboard inference
